# Feishu Markdown Exporter

一个本地运行的 Chrome 扩展：在可阅读的飞书或 Lark 文档页面，点击扩展图标即可导出 Markdown。

## 本地加载

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 打开可阅读的飞书文档，点击扩展图标并选择“导出当前文档”。

## 隐私与边界

- 只在用户点击按钮后读取当前标签页。
- 不上传文档，不保存登录 Cookie，不连接后端服务。
- 不能导出当前账号无权阅读的内容，也不支持旧版 `/doc/` 页面。

## 发布前检查

- 在 Chrome Web Store 后台上传打包 ZIP。
- 如实填写单一用途、权限理由和用户数据声明。
- 使用真实公开文档与已授权私有文档分别验收。
